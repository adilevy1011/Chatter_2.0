# Chatter 2.0

Chatter 2.0 is a private messaging web app built to run on a live server and be accessed through its domain:

**https://chatter-2.com**

The project is not meant to be run like a traditional local-only app. The production version is hosted on a Droplet and accessed through the domain above.

## Overview

Chatter is a full-stack messaging application with support for user accounts, contacts, real-time chat behavior, notifications, media/file messages, and server-side message handling.

## Project Structure

The exact structure may change over time, but the current project includes:

* Backend/server code
* Frontend/static files
* Upload handling
* Authentication functionality
* Messaging and contact logic
* Notification logic
* Runtime files created on the server

## Production Domain

The app is currently accessed at:

**https://chatter-2.com**

The app is intended to be used through the deployed domain, not through a local development URL.

## Current Status

Chatter 2.0 is actively being developed and improved.

Recent areas of work have included:

* Message display behavior
* Typing indicators
* Read/unread behavior
* File and media message handling
